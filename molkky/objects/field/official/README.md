# Official field marker

The active launching-zone marker is `images/molkkaari.webp`.

The game field is calibrated so the front row of the initial pin formation is
3.5 metres from the Mölkkaari. The throwing origin remains behind the marker.

The in-game marker is intentionally rendered at a compact presentation scale so it
identifies the official launching zone without covering the playfield. This does not
change the fixed 3.5 metre gameplay calibration.
The marker follows the official four-piece trapezoidal layout, with the two
side pieces angled toward the player.

This asset and its drawing code are presentation-only. Collision, scoring,
pin order, and pin recovery are unchanged.
