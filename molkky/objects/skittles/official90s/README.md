# Official 90s skittle art

The numbered skittles are stored as twelve independent lossless WebP images in
`images/`. They use the official Mölkky proportions as their shape reference:

- numbered skittle height: 150 mm
- diameter: 59 mm
- numbered face: 45-degree bevel

Only the presentation layer uses these files. Pin placement, collision,
scoring, and recovery remain in `game.js` and are unchanged by this art pack.
